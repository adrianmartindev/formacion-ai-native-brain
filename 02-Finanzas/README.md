# Plan de negocio y modelo financiero

**Qué va aquí:** plan de negocio, modelo de ingresos y costes, escenarios, unit economics, supuestos, hitos financieros y riesgos.

**Qué NO va aquí:** precios de cara al cliente (van a `06-Ventas`), facturas, nóminas ni datos bancarios: eso no entra en el brain.

**Aviso:** carpeta confidencial. No se enseña en pantalla ni se sube a servicios externos.

Las plantillas de cada tipo de documento están en [`_plantillas/`](_plantillas/).
