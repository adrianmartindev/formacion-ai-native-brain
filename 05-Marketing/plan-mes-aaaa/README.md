# Plan de marketing del periodo

**Qué va aquí:** el plan de marketing de un periodo concreto y su calendario de contenidos. Cuando entra el primer plan, la carpeta se renombra a `plan-<mes>-<aaaa>` (por ejemplo, `plan-enero-2027`); cada periodo nuevo tiene su propia carpeta.

**Qué NO va aquí:** la estrategia de largo plazo (va a `../estrategia-y-canales/`).

Las plantillas de cada tipo de documento están en [`_plantillas/`](_plantillas/).
